Pocket Memory lightweight package (models not included)

Start:
1. Unzip the package to a writable folder.
2. Put optional local models under the models folder described in models\README.txt.
3. Double-click PocketMemory.exe.

Without models, note creation, editing, local Markdown files, backups and keyword search work normally.
OCR, semantic search, automatic organization and intelligent Q&A remain unavailable until their matching local model files are added. The app never downloads models automatically.

Data:
- Notes, SQLite, Markdown files, images, and indexes are stored in the data folder beside PocketMemory.exe.
- You can move the whole folder to another Windows computer.

Backup:
- Use the in-app ZIP backup command. It includes the database, Markdown files, tabs, and attachments.
