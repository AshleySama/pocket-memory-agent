# Pocket Memory 1.0.7

本版整合已经验证的直答扩展、原文定位和托盘提示修复，保留现有本地4B与已接受的界面。

## 用户可见变化

- 原文存在完整、边界明确的清单或小节，且问题范围、主体和问项能够确定时，可直接展示有据内容及引用。条件、例外、冲突和必要上下文保留；不确定或需要综合推理的问题仍走既有4B路径。
- 修复引用尾注、编号和轻微措辞改写导致的漏高亮。只在已引用、版本一致的原文中定位，多个候选或无法确认的位置保留完整上下文；不把整段全文冒充精确证据句。
- 关闭桌面窗口后不再反复弹出“仍在运行”的通知；可从托盘恢复窗口或右键退出。

高亮只是阅读定位，不是答案正确性证明。复杂跨文档推理、大幅改写、条件理解和部分长文报告仍需核对。直答有适用条件，不能把少数题的结果外推为所有问答提速。

新安装默认开启AI自动整理和后台预热。升级保留已有开关、模型、资料和配置；本版没有改动更新流程或资料格式。

## 交付与验证

完整包为 `PocketMemory-latest.zip`，内部目录 `PocketMemory-1.0.7`，包含现有4B及配套本地模型。程序包为 `PocketMemory-1.0.7-Program.zip`，不含模型。`PocketMemory-update.json` 对应程序包的版本、大小及SHA256。腾讯云先上传两个ZIP，再覆盖更新清单。固定完整包、视频链接不变；GitHub源码发布不代表COS已更新。

复用与本次源码一致的清单／小节直答、真实接口问答、引用点击及反例验证。三个自由生成风险问法在开发机上均从仅一条定位变为三条定位，耗时仍约22–27秒，不声称生成提速。历史100题仅做准入及显示回放，不能当作新百题准确率。目标T14s没有本版新增性能实测。

发行检查覆盖最终EXE桌面启动、包内资源、程序文件及模型身份、版本和更新清单。具体本机发布执行记录保存在交付文件夹；未将历史升级／回退测试或浏览器检查冒充本版目标机桌面验收。

本库不包含模型、安装包、私人笔记、测试库或本机诊断日志。保留原作者署名、第三方许可、README中的Pages链接和演示截图。
