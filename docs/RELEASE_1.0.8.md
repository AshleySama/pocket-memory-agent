# Pocket Memory 1.0.8

已有笔记和页签在停笔约1.5秒后自动保存到资料库。保存状态显示在编辑器中；“阅读”用于结束编辑，不再是保存的必要步骤。新笔记仍需首次保存，避免产生空笔记。

## 保存与恢复

- 自动保存按顺序执行，快速输入和切换笔记不会被旧响应覆盖。中文输入法尚在组词时等待输入完成。
- 保存失败保留本机草稿；遇到另一窗口改过同一正文时提示冲突，不覆盖远端新内容。可以通过草稿恢复为副本。
- 历史版本保留本次编辑前的恢复点；连续停笔保存不再每次消耗一个历史名额。长时间编辑每约60秒补一个检查点。
- 已保存正文立即进入检索更新；AI分类和标签在连续编辑停下约15秒后合并整理，旧正文产生的AI结果不写回新正文。

## 同时保留的修复

- 待办提取为空时，可恢复原文明确给出日期和动作的事项，不补造负责人或年份。
- 完整照录的列表只有在入模原文可唯一证明其支持来源时才修复引用；保留步骤、条件、来源身份及原文位置。泛化语义错引仍需人工核对。
- 保留现有4B、精确高亮、直答、专题报告、导入、主题、托盘和更新修复。

## 验证边界

本批验证保存、切换、输入法、失败恢复、多窗口冲突、历史版本及后台任务生命周期；复用上一批未改变输入的RAG记录，不把单元测试或历史回放称为新的准确率成绩。保存检查使用隔离资料库，不写入用户资料。

没有更换模型、资料格式或升级协议。程序更新包不含模型；完整离线包包含既有4B及配套模型。新安装默认开启AI自动整理和后台预热；升级沿用已有设置。另一台电脑的实际升级及办公负载需在上传后验收，本批不宣称已在目标电脑完成。
