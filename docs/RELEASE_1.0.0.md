# Pocket Memory 1.0.0

首次面向新用户正式上线，使用SemVer 1.0.0。此前1.2.x是未正式上线的内部候选编号，保留历史记录，不作为1.0.0的自动升级前序。未来修复版使用1.0.1。

保留已验收的本地4B问答及引用、六类报告、草稿恢复、文件导入与重试、本地待办/文字加工、目录浏览与程序更新。侧栏统计去掉重复的总笔记，仅保留今日、本周、分类、标签；全部笔记行仍显示总数量。

完整离线包归档名PocketMemory-1.0.0.zip；腾讯云稳定入口名PocketMemory-latest.zip，两者内容及SHA256相同。包内目录和EXE版本均为1.0.0。程序更新包PocketMemory-1.0.0-Program.zip不含模型，更新清单不引用latest完整包。
