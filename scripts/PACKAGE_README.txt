Pocket Memory 1.0.0 — 正式版完整离线包

首次使用（Windows 10/11，64位）
1. 将整个 ZIP 解压到有写入权限的新文件夹，例如 D:\PocketMemory。不要在压缩包内运行。
2. 双击 PocketMemory.exe。无需安装 Python，也无需另行下载现有模型。
3. 首次打开会创建本地资料库；可在设置中查看或选择资料目录。不要只复制 EXE，保留 _internal、models 和 licenses。
4. 需要完全退出后台时使用应用菜单的退出操作；也可用同一 EXE 的 --quit 参数。

模型与资料
已含 Qwen3-4B-Instruct-2507 Q4_K_M、中文检索、重排、OCR模型。模型和资料均保存在本机，不调用云模型。
首次启动会后台预热模型；纯CPU办公电脑上的长问答仍可能需要几十秒，请核对答案与引用。
本包不含维护者的私人资料、配置、问答历史或备份。安装目录和资料目录请保留写权限并定期备份。

已有功能
笔记/多页签/历史版本、草稿恢复、文件导入重试与浏览器暂存、全文搜索和带来源问答；六类专题报告、图表、引用及HTML导出；待办提取与文字加工（普通Excel文件导入保留，独立Excel分析工作台已下线）。
未提交文件暂存依赖同一浏览器及地址；清理浏览器存储会清除尚未入库的暂存文件。

以后更新
后续可在“设置 → 软件更新”检查新版，只下载程序，沿用模型、资料和配置；检查失败不替换当前程序。请勿手工覆盖 _internal。
