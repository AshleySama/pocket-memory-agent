Pocket Memory 1.2.0-beta.1（2026-10-29，完整离线模型测试包）

推荐启动方式
1. 将整个ZIP解压到有写入权限的文件夹，不要在压缩包内运行。
2. 双击 Start-Beta.bat。Beta使用本目录 data-beta 和 beta-profile，和旧版资料/配置分开。
3. 保留 PocketMemory.exe、_internal 和其他同级文件，不要只发送一个EXE。
4. 完全退出Beta后台请运行 Stop-Beta.bat。关闭窗口不一定退出后台。
5. 如果直接双击 PocketMemory.exe，会沿用该Windows用户此前的配置；首次测试建议用 Start-Beta.bat。

模型和离线运行
- 已含现有 Qwen3-4B-Instruct-2507 Q4_K_M GGUF、BGE中文向量模型、RapidOCR、MultiBERT重排和必要运行资源。
- 无需首次下载这些模型；缺少WebView2时可使用本机浏览器。
- 4B默认保持驻留，设置可手动释放。首次加载和长文准备可能较慢，并不承诺所有问题5–15秒。
- 未更换模型、未引入云端问答，未包含用户笔记或公司测试资料。

已有资料怎么测试
- 先在旧版“设置→数据”导出完整备份，保留旧程序和原资料目录。
- 停止Beta后，将备份完整解压到本包 data-beta 目录（数据库/notes/attachments等直接位于该目录），再用 Start-Beta.bat 启动。
- 也可在Beta“设置→数据”切换到其他备份副本；注意 Start-Beta.bat 下次仍会指定 data-beta。
- 不要让新旧程序同时修改同一份资料；回退旧版时继续使用旧目录或备份。
- 用户资料备份另外存放，不随此软件包和GitHub源码分享。

本次主要变化
- 保留4B，整合本地检索、重排、表格字段边界、多页签和来源身份管理；澄清时可以打开候选资料。
- 问答来源区隐藏技术字符区间、减少重复上下文，多来源更容易区分。
- 笔记默认阅读，编辑时显示格式栏；置顶/收藏/更多分组；保存状态与实际请求一致，失败可重试。
- 保留原五主题、默认泠川、彩虹悬停、问答流光、Enter提示和Logo。

明确限制
- 这是Beta，不是事实可靠性已验收的稳定生产版。复杂条件题可能多答，跨文档可能漏答或语义错引，长回答可能截断。
- 编号能点击不代表每句话都有充分依据；重要数字、金额、权限、日期等必须打开原文核对。
- OCR、复杂表格、扫描文件及较低性能办公电脑仍需要实际人工测试。
- 保存失败的正文草稿保留在当前页面；刷新/关闭后的草稿恢复尚未实现。
- 当前包未做Windows商业代码签名。校验值见包外SHA256清单。
