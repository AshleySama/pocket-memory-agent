让你的资料，随时成为可核验的答案。

Pocket Memory Agent 将零散笔记、图片与文档组织为可检索、可引用、可持续维护的本地个人知识库。答案不止是一段话，还能回到它来自的原文。

核心能力

不是把资料堆在一起，而是让它们在需要时可被准确找回。

01

笔记与页签

用页签承载一个笔记的多个主题，支持富文本、表格、图片与历史版本，方便持续记录与编辑。

02

文件知识库

导入 TXT、Word、Excel 和 PDF。文档会保留在本机，并按章节、页码、工作表和行范围建立可定位索引。

03

智能问答

关键词与语义检索共同寻找证据。回答显示来源与证据句，找不到依据时会明确提示资料不足。

04

有序整理

本地模型可辅助生成标题、分类与标签；用户仍能编辑、删除和确认，知识库的组织权始终在自己手里。

开始使用

从保存第一条资料，到回答第一个问题，只需要三个步骤。

  1. 01

    解压并启动

    下载完整 ZIP 包后解压，双击 PocketMemory.exe，无需准备 Python 环境。

  2. 02

    记录或导入资料

    新建笔记、粘贴截图，或导入已有的文件。长文和表格会以可追溯的位置进入知识库。

  3. 03

    用自然语言提问

    直接提出日常问题，查看答案、证据句和来源；点击来源可回到对应的笔记、页签或文档片段核验。

适用场景

为长期积累资料的人，留下一种更可靠的工作方式。

个人工作沉淀

会议、项目与方法论

将会议纪要、项目复盘、流程经验和零散灵感放回一个可检索的工作台，减少“记过但找不到”。

学习与研究

长文、截图与资料卡片

把阅读笔记、图片文字、章节资料与问题线索串联起来，在复习或写作时回到原始依据。

个人资料管理

文件、表格与决定记录

对本机资料做有来源的问答和定位，不必为了查找个人内容把文件上传给外部平台。
