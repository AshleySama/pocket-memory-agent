Pocket Memory 绿色便携版

如何使用：
1. 将压缩包完整解压到当前 Windows 用户有写入权限的文件夹。
2. 双击 PocketMemory.exe；不要单独移动或删除 _internal 文件夹。
3. 打开设置，在“推荐模型安装”中下载并校验一次性 2.5 GB 的 Qwen 4B 模型。

本地已包含：
- 应用运行时、文档导入、BGE 向量检索模型与 OCR 模型。

按需下载：
- 经审核的 ModelScope 来源 Qwen3-4B-Instruct-2507 Q4_K_M。
- 下载支持断点续传，并在启用前执行固定 SHA-256 校验。

数据：
- 笔记、SQLite、Markdown、图片和索引保存在 PocketMemory.exe 同级的 data 文件夹。
- 移动或升级前，请使用应用内的 ZIP 完整备份。
