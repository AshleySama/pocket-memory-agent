CORE CAPABILITIES

笔记、文件与关联，放进同一个工作台。

会议记录、项目资料、学习材料和工作文档，可以在这里持续整理。写下来的内容、导入的文件和笔记之间的联系，都能接着积累。

多页签笔记文件与 OCR双链阅读知识图谱可追溯问答待办与文字助手专题报告
NOTE WORKBENCH

笔记不再被一页内容限制。

同一个主题可拆成多个页签，例如“背景、方案、风险、行动项”。支持富文本、表格、图片、链接、颜色、历史版本，以及分区、收藏与置顶，既适合快速记录，也能承载长期维护。

怎么用：点击 新建笔记 后直接在右侧工作区写作；需要展开同一主题时，用 新增页签 管理，不必把所有内容塞进一篇超长正文。

FILE LIBRARY

文件保留原貌，也能进入检索。

导入 TXT、DOCX、XLSX、PDF 和图片后，系统保留原始附件，并按标题、段落、页码、工作表和表格行等结构建立可定位内容。图片与扫描件可使用本地 OCR 提取文字，原件、切片与检索位置可以分别查看。

怎么用：在 导入文件 中选择多个文件或一个文件夹；文档默认在“文档”视图集中查看，可重建索引、替换原件、下载原件，或从智能问答直接打开命中的位置。

BIDIRECTIONAL LINKS

用双链，把零散笔记接回上下文。

在笔记中通过链接引用另一篇笔记，阅读时可点击跳转到目标内容。系统同时保留反向关系，因此一篇项目笔记被哪些专题、复盘或行动项引用，不必靠人工回忆。

怎么用：在正文中插入并选择目标笔记；阅读引用时点击链接进入 只读参考笔记，核对后可返回原笔记继续编辑，避免误改来源内容。

LOCAL RELATION MAP

把笔记之间的联系看清楚。

知识图谱以笔记间的双链和共用标签为线索展示关联，也能显示孤立笔记。它适合发现某个项目、主题或标签周边已经积累了什么，以及哪些资料还没有被纳入任何脉络。

怎么用：打开 知识图谱，按标题或标签筛选；勾选“显示孤立笔记”检查未关联内容。图谱用于浏览与整理，不参与智能问答的默认证据库。

ORGANIZE WITH CONTROL

整理有辅助，最终仍由人掌握。

系统可根据笔记内容给出分类与标签建议，建议由你确认和调整。分类路径、手工移动、排序、收藏和置顶共同解决“资料越来越多以后找不到”的问题。

怎么用：先用分区表达稳定结构，用收藏表达高频资料；对 AI 建议的标签保持审阅，不需要的标签可以直接删掉，保持标签清晰。

一个界面完成资料浏览、笔记编辑、智能问答和证据核对；左右分栏可根据使用习惯调整宽度。

  • 1中间先看资料，再决定是否打开笔记与文档分开呈现，分类路径、摘要、最近更新、收藏和置顶状态帮助快速判断下一步。
  • 2右侧专注编辑或问答同一个区域在笔记编辑、AI 回答、工具之间切换，避免因为开启多个窗口而丢失上下文。
  • 3引用不是装饰，而是核对入口回答中的来源可打开参考笔记或原始文档，核对相应页签、段落、页码或工作表位置。
  • 4数据可迁移、可备份可导出完整 ZIP 备份，也可切换本地资料目录。换电脑或清理资料前，先保存好备份与原文件。

TRACEABLE LOCAL RAG

问自己的资料，答案旁边有出处。

Pocket Memory 的智能回答先在用户自己的笔记和文件中检索证据，再用本地模型组织结论。回答里的来源编号连接到原文，重要结论可以逐项核对。

待办与文字助手

把记录整理成待办，
把文字写得更清楚。

内置本机小模型 · 结果由你确认

一段会议记录、一条工作消息、一份说明，从已有文字出发，整理下一步要做的事，或把表达调整得更通顺。

  1. 取用文字，直接开始使用当前笔记、选中文字，或粘贴一段内容，无需来回整理文件。
  2. 提取待办，核对后保存整理事项、负责人和原文期限。核对并修改待办草稿，保存后按需设置提醒。
  3. 加工文字，保留原笔记润色表达、精简内容、礼貌措辞、纠正错别字。结果可继续编辑、复制，或另存为新笔记。
适合处理多长的文字？

每次不超过 1000 字，最多提取 8 条待办。原文没写明的负责人或期限留空，提醒时间由你选择。

处理结果不会覆盖原文。润色后仍请核对原意、姓名、数字和日期。

常见问题

资料会发送到云端模型吗？

笔记和文件保存在本机，问答与报告使用本地模型，不把资料发送给云端模型。

没有独立显卡，普通办公电脑能用吗？

可以，无需独立显卡。回答速度取决于电脑性能、可用内存、资料长度和正在运行的软件。

回答和报告需要人工核对吗？

需要。复杂问题或识别不清的扫描件可能漏答、错引；重要结论请通过来源核对，报告初稿审阅后再使用。

待办和文字处理会直接改动原笔记吗？

不会。先生成可以核对、修改的结果，待办确认后保存；文字结果可复制或另存为新笔记。润色后仍需核对原意、姓名、数字和日期。

报告导出后，别人能直接看吗？

可以导出单文件 HTML，用浏览器打开。报告保留引用及相关依据；接收者不会自动得到整个资料库。分享前请检查报告内的来源和明细是否适合分享。

第一次启动需要额外下载模型吗？

完整离线包已经包含现有 4B 模型和所需组件。完整解压后运行 PocketMemory.exe。

后续怎么更新？模型和资料会丢吗？

在「设置 → 软件更新」检查并安装新版本。常规程序更新保留本地模型、资料和配置，失败时支持回退。
