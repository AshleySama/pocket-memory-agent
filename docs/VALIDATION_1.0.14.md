# 1.0.14 资料汇编排版与引用展示

用户更新说明见[发布说明](RELEASE_1.0.14.md)。

## 变更

- 资料汇编使用原文结构恢复自然段、标题与列表；Markdown以markdown-it-py确定性渲染。只有原文能证实的PDF页码、相邻断行才做显示整理，不重写事实。
- 未设置内容范围时，完整编排所选资料，不为排版调用4B。设置范围仍沿用已有选材分支，已排除的内容不会重新插入。
- 隐藏正文自动引用编号与纯引用行，保留原始引用身份、片段和核对入口。新旧未全文编辑的文稿共用排版；人工全文编辑内容保持。
- 草稿箱移至工具按钮旁，移除常驻提示；资料汇编对话框与左栏增加轻量层次。
- 保留现有4B、RAG主路径、范围筛选规则和1.0.13内置更新恢复。

## 验证

- 冻结源码103项汇编/编辑/导出测试及5组前端草稿/启动检查通过。
- 最终EXE验证9场景：新建汇编与导出、原生桌面就绪、缺独立组件的内置恢复、其他文件损坏拦截、1.0.13到1.0.14升级、内置更新事务、缺件载荷拒绝、无效EXE回滚、真实PDF汇编显示与导出。
- 实际PDF案例188处硬换行降为0；21处已选引用逐字核对，原始文稿、选材和来源快照不变。
- 升级/回滚核对笔记、附件、配置、模型；原24项模型资源哈希保持。未增加模型生成调用。

## 边界

本轮改善原文编排与显示，不声称提高复杂跨文档归纳或选材语义正确率。旧导出HTML需要重新导出。测试在本机隔离库与受控本地更新包进行，不代表同事企业终端策略或公网下载链路已验证。私人资料与验收备份不进入发布包或源码仓库。
