# Pocket Memory 1.0.6

本版集中整理已确认的顶部界面与草稿栏调整，保留现有4B和已有功能修复。GitHub源代码同步不会自动上传腾讯云下载包。

## 用户可见变化

- 搜索栏左缘与中区对齐，侧栏宽度调整及窄窗口时仍保持一致。保留紫色智能问答背景和星星动效。
- 顶部操作按钮统一尺寸、边框、线性图标与居中文字；新建笔记使用更明确的鹅黄色，其他按钮保持淡底。
- 草稿自动保存提示从47px收紧为31px，保留草稿箱、失败提示和重试入口。
- 保留五种主题及原工作台布局。未修改RAG、模型、资料格式、桌面退出或更新流程。

新安装默认开启AI自动整理和后台预热；升级继续沿用已保存的设置。模型、资料和配置不随程序更新重置。

## 交付

| 文件 | 用途 |
| --- | --- |
| PocketMemory-latest.zip | 首次完整离线包，含现有4B及配套模型，内部目录PocketMemory-1.0.6 |
| PocketMemory-1.0.6-Program.zip | 应用内更新使用，不含模型 |
| PocketMemory-update.json | 1.0.6更新信息及程序包大小、SHA256 |

腾讯云发布时先上传两个ZIP，最后覆盖更新清单。固定完整包和视频链接不变。仓库不包含安装包、模型、用户配置、私有资料或本机诊断日志。

## 使用边界与许可

本版主要调整界面，不代表问答准确率或性能提升。长文报告、复杂条件及OCR内容仍需核对；企业环境的安装与更新限制见[安装说明](INSTALL_WINDOWS.md#software-updates)。
