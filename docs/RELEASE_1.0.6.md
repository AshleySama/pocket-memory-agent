# Pocket Memory 1.0.6

本版集中整理已确认的顶部界面与草稿栏调整，保留现有4B和已有功能修复。GitHub源代码同步不会自动上传腾讯云下载包。

## 用户可见变化

- 搜索栏左缘与中区对齐，侧栏宽度调整及窄窗口时仍保持一致。保留紫色智能问答背景和星星动效。
- 顶部操作按钮统一尺寸、边框、线性图标与居中文字；新建笔记使用更明确的鹅黄色，其他按钮保持淡底。
- 草稿自动保存提示从47px收紧为31px，保留草稿箱、失败提示和重试入口。
- 保留五种主题及原工作台布局。未修改RAG、模型、资料格式、桌面退出或更新流程。

新安装默认开启AI自动整理和后台预热；升级继续沿用已保存的设置。模型、资料和配置不随程序更新重置。

## 验证范围

复用与本次冻结前端一致的五主题45种布局、侧栏调整16种对齐组合、草稿栏10种组合、文字对比度、键盘焦点及减少动效设置检查。用户已接受该界面。

新构建EXE在独立空资料库打开Windows原生桌面，显示首次引导和笔记工作台；包内页面资源与冻结源文件逐字节一致。包内宽窄/浅深色布局、草稿箱和设置入口另用本机Chromium验证。桌面鼠标自动化受工具坐标限制，未将网页点击称作原生鼠标验收。

完整包及程序包检查CRC、逐文件SHA256、版本和更新清单对应关系；24项模型与1.0.5相同。完整包不含私人资料或测试配置。没有更换模型或重跑问答百题，没有新增准确率/提速承诺。

本轮未重复执行实际跨版本升级/失败回退，也未在T14s上重新运行；更新和存储实现与1.0.5保持一致，历史验证不冒充本版实测。原有长文报告过长、复杂条件及OCR需要核对等边界保留。
