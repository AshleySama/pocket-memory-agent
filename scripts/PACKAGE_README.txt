Pocket Memory 1.1.1 同事测试版（2026-10-12，含完整本地模型）

本次更新：
- 包含 10 月 11 至 12 日的 RAG 修复：表格按名称与字段取证、“关于”问法、同主体多字段与单字段、Agent 空格边界，以及引用定位和制造业阶段来源补全。
- 保留已确认的原主题、右侧标签、Enter 提示、问答流光和放大 Logo。
- 本包仅含程序及模型，不含用户笔记、测试资料库或个人配置。

如何使用：
1. 将压缩包完整解压到当前 Windows 用户有写入权限的文件夹。
2. 双击 PocketMemory.exe；不要单独移动或删除 _internal 文件夹。
3. 本包包含 Qwen3-4B GGUF、BGE 向量模型和 OCR 模型，无需首次下载这些模型。
4. 首次启动会在后台预热模型，请等待状态就绪后提问；耗时取决于电脑性能。
5. 默认风格为“泠川”；已有用户配置会保留之前的选择。

本地已包含：
- 应用运行时、Qwen 4B 智能问答模型、BGE 向量检索模型、OCR 模型与文档导入能力。

数据：
- 笔记、SQLite、Markdown、图片和索引保存在 PocketMemory.exe 同级的 data 文件夹。
- 移动或升级前，请使用应用内的 ZIP 完整备份。
- 如该电脑以前运行过本工具，会沿用已保存的数据目录；可在“设置 → 数据”中检查。
- 程序配置保存在当前 Windows 用户的 %LOCALAPPDATA%\PocketMemory\config.json。

测试说明：
- 本包供 Windows 同事手工测试，未代表目标电脑或真实业务验收通过。
- 答案可能遗漏或误拒，请结合引用原文核验；历史延期问题仍保留，本次未声称解决所有 RAG 问题。
- 关闭窗口后后台服务可能仍运行；需完全退出时，可在本目录执行 PocketMemory.exe --quit。
- 请完整解压后运行，不要在压缩包内直接双击，也不要只发送单个 EXE。
