Pocket Memory 1.0.12 — 正式版完整离线包

首次使用（Windows 10/11，64位）
1. 将整个 ZIP 解压到有写入权限的新文件夹，例如 D:\PocketMemory。不要在压缩包内运行。
2. 双击 PocketMemory.exe。无需安装 Python，也无需另行下载现有模型。
3. 首次打开会创建本地资料库；可在设置中查看或选择资料目录。不要只复制 EXE，保留 _internal、models 和 licenses。
4. 需要完全退出后台时使用应用菜单的退出操作；也可用同一 EXE 的 --quit 参数。
5. 双击EXE打开桌面窗口，不会因窗口报错自动跳转浏览器。首次启动会在EXE旁创建 PocketMemory.exe.config，用于.NET加载随包窗口组件；请保留该文件。
6. 模型加载失败时可在“设置 → 智能”点击“重新加载”；完整性异常请从完整包恢复模型，不需删除资料。
7. 已有用户可通过“设置 → 软件更新”更新至1.0.12，沿用模型、资料和配置；不要手工覆盖 _internal。若提示缺少组件或旧版更新失败，请先保存笔记、记录资料库位置并导出完整备份，从托盘完全退出旧程序，将本次完整包解压到新文件夹后启动并选择原资料库；保留旧目录与备份，不需要单独补组件。

模型与资料
已含 Qwen3-4B-Instruct-2507 Q4_K_M、中文检索、重排、OCR模型。模型和资料均保存在本机，不调用云模型。
首次启动会后台预热模型；纯CPU办公电脑上的长问答仍可能需要几十秒，请核对答案与引用。
本包不含维护者的私人资料、配置、问答历史或备份。安装目录和资料目录请保留写权限并定期备份。
启动异常会记录到资料目录下的 logs/launcher-日期.log；后台日志在同目录的 server-日期.log。反馈故障时可提供对应日志，请先检查其中是否含私人路径或内容。

已有功能
笔记/多页签/历史版本、草稿恢复、文件导入重试与浏览器暂存、全文搜索和带来源问答；资料汇编、全文编辑、引用及HTML导出；待办提取与文字加工（普通Excel文件导入保留，独立Excel分析工作台已下线）。
未提交文件暂存依赖同一浏览器及地址；清理浏览器存储会清除尚未入库的暂存文件。

以后更新
后续可在“设置 → 软件更新”检查新版，只下载程序，沿用模型、资料和配置；检查失败不替换当前程序。请勿手工覆盖 _internal。
