    备份包含数据库、Markdown、图片、页签和自定义资源，可用于完整恢复。

            欢迎使用 Pocket Memory

            你的本地 AI 笔记助手。所有数据存在本机，零云端依赖，零 API 费用。

            模型会在启动后后台预热，首次问答通常无需等待完整加载。

            ⌨️

            快速记笔记

            按 Ctrl+N 新建笔记，写完按 Ctrl+S 保存。

            支持粘贴截图，会自动 OCR 识别文字。

            智能问答

            在搜索框输入问题，点击「智能问答」，基于你的笔记生成本地回答。

            支持跨笔记、跨页签检索，来源可点击跳转。

            🚀
