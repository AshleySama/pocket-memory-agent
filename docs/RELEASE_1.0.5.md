# Pocket Memory 1.0.5

本版保留 Qwen3-4B-Instruct-2507 Q4_K_M，改进 PDF 引用、长文报告与桌面操作。升级沿用本地资料和已有设置。

## 用户可见变化

- PDF 问答引用展示与高亮按定位范围呈现，保留完整来源用于核对。
- 长篇 PDF 的学习／研究报告增加知识点覆盖与条件保留；归纳以保存的原文单元绑定引用，不以自由补写替代缺失材料。
- 报告导出提示收敛，保留打开报告、文件夹、复制保存路径与下载 HTML 的入口。
- 关闭桌面窗口后可从通知区域双击恢复；右键「退出」结束应用。托盘不可用时有退出保护。
- 「选择资料目录」恢复 Windows 原生目录窗口。选择不会立即迁移或切换资料，仍需确认后续操作。
- 本次源码同步也包含此前发布线的桌面 DLL 加载、Windows 短路径、模型加载诊断及更新交接修复。

新安装默认开启 AI 自动整理与后台预热；升级保留用户已保存的设置。完整包包含模型，程序更新包不包含模型；更新继续沿用现有资料、模型和配置。

## 交付文件

| 文件 | 用途 |
| --- | --- |
| `PocketMemory-latest.zip` | 新用户完整离线包；内部目录为 `PocketMemory-1.0.5` |
| `PocketMemory-1.0.5-Program.zip` | 旧用户应用内更新；不含模型 |
| `PocketMemory-update.json` | 更新检测，指向上述程序更新包及其大小、SHA256 |

发布时先上传两个 ZIP，最后更新清单。完整包固定下载地址、宣传视频地址保持不变。模型、安装包、私人资料和本地诊断结果均不放入 Git。

## 使用边界

长文报告仍可能过长、遗漏细节或继承源资料矛盾，应核对引用。本版不承诺总体准确率或跨设备提速；企业环境的安装与更新限制见[安装说明](INSTALL_WINDOWS.md#software-updates)。
